# Test Scope

## In Scope

The project will cover representative REST API operations:

- GET
- POST
- PUT / PATCH
- DELETE

Testing will include:

- valid requests
- invalid requests
- required and optional fields
- valid and invalid IDs
- query parameters
- request body validation
- response body validation
- status codes
- response headers
- content type
- response time observation
- authorization where available
- request chaining
- Postman variables
- basic automated checks

## Out of Scope

- Load testing
- Penetration testing
- Backend database validation
- Production infrastructure
- Full security audit
- Source code review
