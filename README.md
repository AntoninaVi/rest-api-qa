# REST API QA

QA portfolio project for testing a public REST API using Postman.

The project demonstrates API test design, positive and negative testing, request chaining, response validation, and basic automated checks.

## Project Goal

The goal of this project is to practice and demonstrate a structured approach to REST API testing.

Main areas:

- HTTP methods
- Status codes
- Request parameters
- Request body validation
- Response body validation
- Headers
- Positive and negative testing
- Boundary checks
- Postman variables
- Request chaining
- Basic Postman tests
